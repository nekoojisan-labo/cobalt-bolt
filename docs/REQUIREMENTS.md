## 1. 目的・成功状態

- 立ち・走り・ジャンプのどの状態でも、バスターを肩から構えて攻撃している人体動作に見える。
- 走りながらチャージしても、脚は走り続け、上半身はバスターを狙って構え続ける。
- 通常立ち姿の腕も、肩から肘・手へ自然につながる。

## 2. 状態別の承認内容

| 状態 | 下半身 | 上半身・腕 |
|---|---|---|
| 立ち撃ち | 両足を接地して踏ん張る | 胸を安定させ、肩→肘→バスターを前へ向け、発射時だけ小さく反動 |
| 走り撃ち | 走行サイクルを維持 | 上体の揺れを抑え、肩から照準姿勢を維持 |
| ジャンプ撃ち | 上昇・頂点・下降の脚姿勢を維持 | 上体を少し起こし、空中でも肩から前方へ照準 |
| 走りチャージ | 走行サイクルを維持 | 発射反動なしで照準姿勢を保持し、砲口の蓄光だけ成長 |
| 通常立ち | 両足を自然に接地 | 肩から腕が下がり、肘が人体として自然に曲がる |

## 3. 禁止状態

- 腕が顔・首・胸の中央から生えて見える。
- 肩と上腕、上腕と前腕の間が離れる、または不自然に重なる。
- 通常立ち腕が棒状に垂れる、足元まで届く、胴体へ埋まる。
- 走りチャージ中に腕が走行スイングへ戻る。
- 走り撃ち・ジャンプ撃ちで下半身が立ち姿へ切り替わる。
- 状態ごとに砲口と弾の発生位置がずれる。

## 4. 不変条件

- 骨盤→体幹→肩→肘→バスターの親子関係を全状態で共有する。
- 上腕・前腕・脚の骨長を状態間で変えない。
- 弾とマズルFXは描画と同じ砲口座標から発生する。
- 移動速度、ジャンプ物理、当たり判定、敵、ステージ進行を変更しない。

## 5. 検証方法・受け入れ基準

- 通常立ち、立ち撃ち、走り撃ち、ジャンプ撃ち、走りチャージを同じ倍率で画像化する。
- 各画像で肩の接続、肘の曲がり、胴との重なり、砲口位置を目視確認する。
- 状態別の腕・体幹値が同一値の使い回しでないことを自動検査する。
- 走りチャージ中も `charge` の構えを維持することを自動検査する。
- 既存の全身関節検査とゲーム進行30項目を通す。
- 実ブラウザで操作し、表示エラー0を確認する。

## 6. スコープ外

- キャラクター画像の新規生成・差し替え。
- 移動速度、攻撃力、チャージ時間などゲームバランスの変更。
- ボス・敵キャラクターのモーション変更。
