# COBALT BOLT ⚡

レトロ風の横スクロールアクションゲーム（ブラウザ・単一HTMLファイル）。
青い小型ロボット **COBALT** を操作し、敵をかわしながら1ステージを駆け抜け、最奥のボスを撃破せよ。

> Pure HTML5 + Canvas / 外部ライブラリ・画像素材なし（ドット絵はすべてコード描画）。

## 🎮 遊び方

**▶ オンラインで遊ぶ:** （GitHub Pages 公開URL）

ローカルで遊ぶ場合は `index.html` をブラウザで開くだけ。

### 操作
| キー | 動作 |
|------|------|
| ← → | 移動 |
| Z | ジャンプ（押す長さで高さが変わる・コヨーテタイム / 先行入力対応） |
| X | ショット（長押し→離すでチャージショット） |
| Enter | 決定 / リスタート |

## 🕹 内容
- 横スクロール1ステージ（落とし穴・浮き足場・段差）
- 雑魚敵4種：メット型 / 歩行ロボ / 飛行型 / 砲台
- ボス戦：ジャンプ追撃・拡散弾・ダッシュの3パターン＋HPゲージ
- タイトル / ゲームオーバー / ステージクリア画面、簡易効果音（WebAudio）

## 🧪 開発・検証ツール
ブラウザ目視に頼らず、ロジックと描画を自動／半自動で検証できる仕組みを同梱。

```bash
node harness.js      # ゲームループを実走させ、24項目のロジックを自動テスト
node tools/shot.js   # Canvas2Dをエミュレートして画面をPNG出力（描画の目視確認用）
```

ゲーム側は `globalThis.__GAME`（state / player / enemies / boss / step / hold / release / draw など）を公開しており、検証ツールはこのフックを通じてヘッドレスに駆動する。

## 📁 構成
```
index.html      ゲーム本体（これ単体で動く）
harness.js      ロジック自動テスト
tools/shot.js   描画スクリーンショット生成ツール
```
